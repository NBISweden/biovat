# BioVAT
BioVAT (BIOdiversity Variant Analysis Toolkit), a modular Nextflow pipeline for population genomics analysis of non-model organisms 


## Brief description

`BioVAT` (Biodiversity Variant Analysis Toolkit) is a modular 
Nextflow pipeline for mapping, variant calling, data filtering 
and downstream analyses of population-level whole genome 
resequencing data. 

## Quick start

### Local or HPC installation

- [Install Pixi](https://pixi.sh/latest/installation/): `curl -fsSL https://pixi.sh/install.sh | sh` 
- Clone the pipeline repository: `git clone https://github.com/NBISweden/BioVAT.git`
